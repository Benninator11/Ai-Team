# KI-Team Studio Plus

Ein Python-Desktopprogramm für Linux Mint und andere Linux-Distributionen, das bis zu vier über OpenRouter angebundene KI-Agenten in einem gemeinsamen Softwareprojekt zusammenarbeiten lässt.

Die Anwendung bietet Team-Meetings, eine geführte Planung mit KI-Empfehlungen und Benutzer-Rückfragen, einen Automatikmodus, einen umschaltbaren Dark Mode, dezente Aktivitätsanimationen sowie einen Planen-/Bauen-/Debuggen-Workflow mit gemeinsamem Projektprotokoll.
